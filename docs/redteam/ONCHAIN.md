## Switching the agent off, then deleting its key (sandbox)

After the family's `revoke_agent`, the case shows `agent_enabled: false` and `reserved: 0`; the pending proposal became `Invalidated` (`E_AGENT_DISABLED`).
A new proposal is refused with `E_AGENT_DISABLED`, the agent cannot call `enable_agent` (NEAR: `MethodNameMismatch`), and once the account's setup key deletes the agent key, nothing it signs is accepted. Covered by `src/server/near/bypass.sandbox.ts`.

## Targeted mutation checks

| Control | Mutation caught | Failing tests |

| The family's approval must carry the hash of the exact stored proposal | yes | — |
